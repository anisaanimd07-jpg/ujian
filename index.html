Modul 01 — Virtualisasi

Dasar VirtualBox & Setting Jaringan (Wajib Praktikum)

1.1 Rekomendasi Spesifikasi VM Ringan untuk PC Lab Sekolah

Karena komputer di laboratorium sekolah sering memiliki RAM terbatas (4 GB – 8 GB) dan menjalankan 2 VM sekaligus (Server + Client), gunakan alokasi resource berikut agar tidak hang:

Base Memory (RAM) 1024 MB (1 GB) Cukup untuk mode CLI Server
Processor (CPU) 1 - 2 Core Tetap di zona hijau slider
Virtual Hard Disk 15 - 20 GB (VDI) Dynamically Allocated
Display & Audio 16 MB / Disable Matikan Audio & USB 3.0

1.2 Perbandingan 4 Mode Network Adapter VirtualBox

Mode Network Akses Internet Komunikasi Host & VM Fungsi Utama dalam Praktikum SMK
NAT Ya (Otomatis) VM → Internet saja (Terisolasi dari Host) Adapter 1 (eth0/enp0s3): Wajib dipakai saat ingin apt update dan mengunduh paket aplikasi dari repositori internet.
Host-Only Adapter Tidak Dua Arah (Windows Host ↔ VM) Adapter 2 (eth1/enp0s8): Menghubungkan Windows asli dengan VM Linux agar bisa remote SSH via PuTTY dan uji buka Web Server di browser Windows.
Internal Network Tidak Antar sesama VM saja (misal: intnet) Simulasi UKK Full VM: Menghubungkan VM Debian Server ke VM Windows 7/10 Client di dalam VirtualBox untuk uji DHCP Server dan DNS.
Bridged Adapter Ya (Satu segmen LAN) Semua PC di Lab Sekolah VM seolah-olah menjadi komputer fisik baru di jaringan kabel/Wi-Fi lab sekolah. Hati-hati jika menyalakan DHCP Server (bisa bentrok dengan router lab!).

Modul 02 — Fundamental CLI

Perintah Dasar Linux & Manajemen Direktori / File

2.1 Struktur Hierarki Direktori Penting di Linux Server

Linux tidak mengenal drive C:\ atau D:\ seperti Windows. Semua folder berawal dari direktori akar tertinggi yaitu / (root directory):

/

Root Directory: Puncak tertinggi dari seluruh sistem file Linux.

/etc

Configuration Files: Menyimpan semua file konfigurasi layanan (interfaces, sources.list, bind, apache2).

/var/www/html

Document Root Web: Direktori tempat menyimpan file HTML/PHP website pada Apache2 atau Nginx.

/home

User Home: Direktori pribadi untuk user biasa (misal: /home/siswa).

/root

Superuser Home: Direktori khusus milik administrator tertinggi (root).

/var/log

System Logs: Menyimpan catatan aktivitas & error sistem untuk troubleshooting.

Perintah Fungsi & Contoh Penggunaan
pwd Print Working Directory — Menampilkan lokasi direktori aktif saat ini.
ls -la Menampilkan daftar seluruh isi folder termasuk file tersembunyi (diawali titik) dan detail hak akses.
cd Change Directory — Pindah folder. Contoh: cd /etc/network atau cd .. (naik 1 tingkat).
mkdir -p Membuat folder baru. Opsi -p membuat sub-folder bertingkat sekaligus.
touch Membuat file kosong baru (misal: touch index.html).
cp -r Menyalin file/folder (wajib gunakan -r jika menyalin direktori beserta isinya).
mv Memindahkan file/folder atau mengubah nama (rename).
rm -rf Menghapus file atau direktori beserta seluruh isinya secara permanen.
cat / nano cat membaca isi file di layar; nano membuka text editor terminal (Simpan: Ctrl+O, Keluar: Ctrl+X).
Praktikum Manajemen Direktori & File 
# 1. Cek lokasi saat ini & pindah ke direktori /home
pwd
cd /home

# 2. Membuat struktur direktori bertingkat untuk praktikum TKJ
mkdir -p praktikum_tkj/web/assets
ls -la praktikum_tkj

# 3. Membuat file kosong & mengisi teks dengan nano
touch praktikum_tkj/web/index.html
nano praktikum_tkj/web/index.html

# 4. Membaca isi file yang sudah dibuat
cat praktikum_tkj/web/index.html

# 5. Backup (copy) folder konfigurasi sebelum diedit (Wajib di UKK!)
cp /etc/apt/sources.list /etc/apt/sources.list.backup

# 6. Mengubah nama file (rename) & menghapus folder latihan
mv praktikum_tkj/web/index.html praktikum_tkj/web/beranda.html
rm -rf praktikum_tkj

Gunakan tombol Tab di keyboard saat mengetik nama file/direktori untuk fitur Auto-Complete otomatis!

2.2 Hak Akses File (chmod & chown) + Kalkulator Interaktif

Setiap file di Linux memiliki 3 kelompok pemilik: Owner (User), Group, dan Others dengan nilai oktal: Read (r) = 4, Write (w) = 2, Execute (x) = 1.

Owner (Pemilik File)
Group (Grup Pemilik)
Others (Pengguna Lain)
Kode Oktal 755
Notasi Simbolik -rwxr-xr-x
Perintah Siap Pakai 
chmod -R 755 /var/www/html && chown -R www-data:www-data /var/www/html

Modul 04 — Networking & Remote

Konfigurasi IP Address Statis & SSH Server

Debian 11 / 12

File: /etc/network/interfaces

Cek nama interface terlebih dahulu dengan perintah ip a (umumnya enp0s3 untuk Adapter 1 NAT dan enp0s8 untuk Adapter 2 Host-Only/Internal).

# Edit file konfigurasi jaringan Debian
nano /etc/network/interfaces

# --- Isi Konfigurasi ---
source /etc/network/interfaces.d/*

# Loopback network interface
auto lo
iface lo inet loopback

# Adapter 1 (NAT - Koneksi Internet)
allow-hotplug enp0s3
iface enp0s3 inet dhcp

# Adapter 2 (Host-Only / Internal Network - IP Statis Server)
auto enp0s8
iface enp0s8 inet static
    address 192.168.56.10
    netmask 255.255.255.0

# Simpan (Ctrl+O, Enter, Ctrl+X), lalu restart service:
systemctl restart networking
ip a
Ubuntu Server 22.04 / 24.04

File: /etc/netplan/00-installer-config.yaml

Perhatikan indentasi (spasi) pada file YAML! Jangan gunakan tombol Tab, gunakan spasi yang sejajar.

# Edit file netplan Ubuntu
nano /etc/netplan/00-installer-config.yaml

# --- Isi Konfigurasi YAML ---
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: true
    enp0s8:
      dhcp4: false
      addresses:
        - 192.168.56.10/24

# Terapkan konfigurasi Netplan & cek IP:
netplan apply
ip a

4.2 Instalasi & Konfigurasi OpenSSH Server (Remote dari Windows)

Dengan SSH, siswa bisa menyalin-tempel (Copy-Paste) perintah dari Windows langsung ke terminal Linux menggunakan aplikasi PuTTY atau Command Prompt / PowerShell Windows! 

# 1. Instal paket OpenSSH Server
apt install -y openssh-server

# 2. (Opsional untuk soal UKK) Mengganti Port SSH default 22 menjadi 2222 & izinkan login root
nano /etc/ssh/sshd_config
# Ubah baris berikut (hapus tanda pagar # di depannya):
# Port 2222
# PermitRootLogin yes

# 3. Restart layanan SSH dan cek statusnya
systemctl restart ssh
systemctl status ssh

# 4. Cara mengakses dari CMD / PowerShell Windows Host (jika menggunakan Host-Only 192.168.56.10):
# ssh siswa@192.168.56.10 -p 2222
